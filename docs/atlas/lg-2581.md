# LG #2581 · Send 到子图，子图返回未声明的 `kids`

**状态**：grounded（ACR007；第二批验证命中）
**一句话症状**：父图用 `Send` 扇出到编译子图，子图的 `get_kids` 返回 `kids`，但 `SubgraphState` 只声明了 `father`；子图边界拒绝这次写入，报 `InvalidUpdateError: Expected node father to update at least one of ['father'], got {'kids': [...]}`。

修复方向在**子图状态声明**，不是父图的 `Send` 逻辑：父图 `kids` 的 reducer 存在，但因为子图从未产生合法 `kids` 写入，它一直没收到值。

## 最小修复

```python
class SubgraphState(TypedDict):
    father: str
    kids: list[str]   # 声明子图节点要写的键

def get_kids(state: SubgraphState) -> dict:
    return {"kids": [state["father"] + " Junior"]}
```

如果 `kids` 只该在子图内部使用，就改成局部变量/返回值映射，不要跨边界写未声明的键。
