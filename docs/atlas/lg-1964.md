# LG #1964 · 两个并行子图把父图状态回传到 sink

**状态**：grounded（ACR001；第二批案例验证命中）
**一句话症状**：两个子图从 `question_generation` 并行扇出，都没有声明 `output_schema`，各自把父图的 `question` 原样回传；汇入 sink 时同一步收到两次 `question` 写入，报 `InvalidUpdateError: At key 'question': Can receive only one value per step`。

## 最小修复

给每个子图声明只包含自己负责键的输出 schema（issue 评论中被采纳的方案）：

```python
class ChildOutput(TypedDict):
    results: list[str]

def create_child(text: str):
    child = StateGraph(ChildState, output_schema=ChildOutput)
    ...
    return child.compile()
```

只加 reducer 能让 `question` 合法并存，但没有解决“子图不该回传父图字段”的所有权问题；`acr` 的 ACR002 在这里只是附带提醒。
