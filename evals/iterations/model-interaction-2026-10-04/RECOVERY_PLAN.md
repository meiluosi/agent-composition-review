# 分类器误熔断后的独立恢复登记

本登记在恢复调用前制定，并将与恢复执行器、回归测试、原 64 份尝试记录一起冻结和推送。它是对运行软件错误的显式修订，不覆盖原预注册方案，也不重新解释或删除原始失败。

## 可核实的停止原因

原冻结执行器在累计 64 次尝试后结束，退出输出为 `stopped_on_infrastructure=true`。唯一 infrastructure_failure 记录为 m01 / gpt-6-astra / A_tools / trial 1，key `f4e02ac31dd8396bcc69`，其机器分类为 auth。

独立查看日志后确认，该 auth 分类来自旧检测函数对整个 stderr 搜索裸数字 `401`。唯一匹配出现在 shell snapshot 文件名 `1791096884019646000.sh`；没有 unauthorized、authentication、sign in、login required，也没有 error/turn.failed 终止事件。它不是 HTTP 状态。原 record、events、stderr 的 SHA-256 分别为：

```text
6ec46b8ba64f3bba30bc22e60ceef07195208272d870276d0c1822a0d3e6484f
b71ae0fbf1107411062f24761a096a1dbcfc570f41ddbd128f77bb5cbc329e9c
fdbc13de5c5d6a88abb48dc7559cfb756f53619b4f25f014d7838e1c7148451e
```

该次执行仍然失败：CLI 在 360 秒上限被结束，退出码 -9，未写出要求的 prediction.json。原始事件中虽有最终消息和 turn.completed/用量，最终源码也通过验收，但这些不能升级成有效交付。原 auth 状态保持原样，维护者只在旁注中纠正原因。也不把 CLI 的最终写出/退出超时直接当作模型推理能力下降。

原进程已经结束，所有 64 个开始记录均有完成的公共记录与产物；没有尚在运行或待决定的原任务。恢复时再次核验这一点，任何其他基础设施失败、记录不匹配或未发布尝试均阻止恢复。

## 恢复范围与不变条件

仅执行原 144 项调度中从未开始的 **80 项**，保持原先的相对顺序。64 个原尝试一律不重跑，包括两条未有效完成记录和所有答错结果。恢复后全项目正式尝试总数最多仍是 144；两个既有 canary 仍单独计数，没有额外 canary 或模型裁判。

原模型别名、高推理设置、CLI/Python/平台版本、三个指导条件、题面、源码、工具、最终输出协议、评分器、三路并发和 360 秒时限全部沿用。m02/m08 的输入或标签问题也不在此阶段修正。所有原冻结文件和记录逐一核对哈希。

唯一行为修订是基础设施错误分类：数字码必须有 HTTP/status 等错误语境，不能从时间戳、路径或普通数字中推断错误。真实额度、鉴权、服务、传输或隔离失败仍停止新增调度；任务超时不触发假鉴权熔断。已开始的尝试仍不能重试，已有真实基础设施失败不能通过重新启动绕过。

恢复使用独立脚本 `scripts/resume_model_interaction.py`；原 `scripts/run_model_interaction.py` 保持冻结。新脚本在运行时显式替换分类函数，其余执行与后置验收复用原代码；新记录写入恢复阶段及恢复清单哈希。恢复清单 `classifier-recovery-manifest.json` 冻结剩余调度、修订代码/测试/本方案、原清单及已存在证据的哈希。任何变化必须另行披露。

可先执行剩余调度的前 3 项检查记录完整性，再按原恢复清单继续。这 3 项属于上述 80 项，不是额外尝试，不能按成绩修改输入或取消其结果。完成后独立重验全部正式产物。

## 报告与解释

原始记录、状态和冻结分析器保持可重放。主成功指标不因这次原因纠正改变：被错误分类为 auth 的那次仍不算有效完成。机器分析器会保留其 infrastructure 标签与原来的禁止升级结果；维护者报告应并列说明原分类与经审计的执行原因，不将该次虚构成真实鉴权故障。

最终必须披露两个执行阶段、各自数量、恢复前后的代码版本和软件差异。不得将本轮描述为无中断的单阶段实验，也不得据此自动升级 Skill。m02/m08 正常标签问题仍然限制误报率和版本门槛的解释。若恢复阶段出现真实基础设施失败，按原停止规则保留失败与 pending，不再利用本登记绕过它。

这是同一有上限开发筛查的透明执行恢复，不是独立保留集、追加重复或对失败答案的补跑。结果仍只能描述这组任务与配置；不得因恢复后某组成绩更好而提升证据等级。
