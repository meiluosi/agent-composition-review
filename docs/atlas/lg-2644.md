## 最小修复

先确认类节点的输入/输出边界，再决定是补进全局 state，还是显式声明节点 schema：

```python
# 方案 A：zoo 确实是图状态的一部分
class State(TypedDict):
    foo: int
    zoo: int

# 方案 B：类节点有自己的私有输入 schema
graph.add_node("node_1", NodeOne(), input=NodeOneInput)
```

ACR007 的 fix 文本会同时给出这两种方向；不要机械地把键塞进全局 state。
