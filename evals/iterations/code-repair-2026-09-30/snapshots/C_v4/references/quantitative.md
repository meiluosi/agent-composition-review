# 定量组合与重构验证

适用于路径替换、压缩、并行化、成本或误差传播。先定义相同输入的两条路径 P/Q、可比较输出、任务距离及外部副作用；只比较语言相似度不能验证业务等价。

若下游 h 在声明范围满足 `d(h(y),h(y')) ≤ L*d(y,y')`，可推出对应误差界。串行累乘需各步距离和范围兼容。经验最大比值不是全局证明，分母为零不可直接求比；阈值附近可直接测动作翻转。相同 Markov 后处理核在总变差距离下不放大距离，不把“误差放大”当作普遍规律。

成本也需要明确组合规则：串行总消耗通常累加，理想无争用并行墙钟可能取最大值再加调度成本；实际限流、共享资源和重试会改变模型。效率一般是预算或优化指标，不是自动保持的不变量。

**验证**：冻结输入、版本、随机性处理和验收容差；比较正常、边界及异常输入的业务结果与效果计数。对反馈检查累计预算与终止。逐项报告准确率、错误断言、误报、token 和时间，不事后合成总分。

理论可用度量、幺半预序或富集范畴组织，具体结构必须验证相应规律。[Fong 与 Spivak，Seven Sketches，资源与富集](https://arxiv.org/abs/1803.05316) 使用普通指标与测试不等于已经构造富集范畴。
