# LG #8320 · 节点返回未声明键，被静默过滤

**状态**：grounded（ACR007；ACR007 设计源，静态命中）
**一句话症状**：节点返回 `{"x": ..., "note": ...}`，但 `State` 只声明了 `x`；图正常结束，`note` 被静默丢掉，没有任何 warning 或 error。

## 最小修复

如果 `note` 本来就属于状态，声明它；如果只是节点局部结果，不要返回：

```python
class State(TypedDict):
    x: int
    note: str  # 需要时声明（多写者再加 reducer）

def node(state: State) -> dict:
    return {"x": state["x"] + 1}  # 只返回 schema 声明的键
```
