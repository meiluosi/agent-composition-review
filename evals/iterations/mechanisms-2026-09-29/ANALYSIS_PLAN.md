# v3 成对机制检查：运行前方案

## 假设与范围

单主入口、按需模块及显式证据维度能否改善对相邻条件的区分？研究具体候选的行为，不把结果解释为范畴论理论整体的证实或否证。

固定六个家族：恢复、实际执行、金额语义、采样/重放、全局资源、读取效应。每家族两个相邻变体，共 12 个自建开发案例。与候选同期编写，已被设计者查看答案，不称保留集或专业数据集。原外部数据与历史评分不变。

## 条件及执行

- A 无 Skill；B 当前 v1 主入口及可读取参考；C v3 候选主入口及可读取参考。每例各两次，共 72 次，不选择性追加。探索阶段两次不能支持稳定发布收益声明。
- 请求 gpt-6-astra / high，当前 Codex CLI，三路并发，单次超时 240 秒。各次新进程、临时目录、只读沙箱；宿主 Skill 发现、插件、网络搜索和多 Agent 禁用。模型服务连接保留。后端精确快照不可见。
- 三组都获得相同共同任务协议、输出 schema 和原始材料，通过相同只读文件工具读取。共同协议已要求保留证据、区分未知，结果反映额外 Skill 的增量收益。
- 有 Skill 的主入口直接注入，参考由执行者自行读取。这是强制激活下的实际按需读取实验，不是自动触发准确率测试，不保证主入口会自然触发。
- 只向执行目录复制 case 的 input 字段以及相应运行包；不复制 oracle、案例 ID、家族、标签文件或他组结果。标签单独由评分进程使用。只读沙箱不是完整读隔离；保留所有可见命令，用白名单解析审计路径，无法解析的调用标记 isolation_unverified，不补跑。
- 随机种子 20260929 固定交错派发顺序，不控制模型随机性或并发完成顺序。先冻结输入、标签、指令、评分器、runner、schema、分析程序和本方案，再运行。运行中不修改冻结内容或看中间分数调参。
- 单次传输预检只读取无关 probe.txt；它不含诊断任务或预期行为，已在正式冻结前完成，不计入 72 次。

## 预先声明的指标

主指标为成对 verdict 成功率：同一 trial 的两个变体均正确才算该家族成功；先按两次重复平均，再按家族等权。主比较 C−A、C−B。按六个家族配对 bootstrap 10,000 次、种子 20260929，报告 95% percentile 区间；样本很小，不作显著性胜者选择或多重比较调整。[0,0] 是经验退化区间，不代表未来确定性。

次要指标分别报告：单例 verdict、verdict 与位置同时正确、命题平均准确率、命题全部正确比例、正常例误报、无效正常例、引用结构合法性、预设证据锚点覆盖。锚点覆盖是狭窄描述指标，遗漏指定锚点不必然意味着缺少合理替代证据；它不决定升级。结构合法与锚点覆盖均不证明自然语言解释真实。

命题标签 supported/refuted/unknown 针对问题文本；反事实未实测时不得假定成功。正常例只有 oracle.satisfied 的五个变体；计划但结局未知的案例单列 insufficient，不挤进正常误报分母。

计划中的缺失、无效或隔离未核实运行在准确率中计失败，正常例无效次数另列，不作为无误报成功。基础设施故障与模型输出错误分开；如果基础设施问题影响解释，只报告受限结论，不用删除分母制造提升。

资源记录输入、缓存部分、输出 token、墙钟和工具调用；reasoning_output_tokens 不再次计入 output_tokens。记录参考文件读取数量与名称，但不把读取更多模块当能力。时间含网络和启动，token 不等于货币费用。

## 判定与公开

本轮为开发阶段候选筛选，不单凭此轮自动替换正式 Skill。即使全过，仍缺少真实任务修复、触发与独立新任务验证。若候选在某家族引入旧版没有的错误或无依据确定性，则留在候选目录并记录失败。若无准确率增益则如实报告；成本上涨单独列出。

完整运行后再计分；逐次结构化预测、工具路径审计、哈希及资源公开；自由文本解释和原始过程保留本地。对解释的人工复盘知道组别，标为开发复盘，不伪装盲评。报告包含各家族表现、两张独立图（机制/成本与固定顺序累计曲线）。累计曲线不是训练曲线，不与历史实验接成进步曲线。

本轮没有让模型执行生产修复或干预；证据检查器用独立确定性负例检查，仅证明它能拒绝列明的不一致记录。
