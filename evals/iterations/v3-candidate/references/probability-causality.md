# 随机性、缓存与因果

## 采样还是复制

先声明请求语义：需要新样本，还是重放同一次结果？在标准随机核模型中，`copy_Y ∘ f` 是采样一次再复制，`(f ⊗ f) ∘ copy_X` 是复制输入后独立采样；两者一般联合分布不同。确定性态射满足保持复制的条件。[Fritz](https://arxiv.org/abs/1908.07021)

工程检查：实际底层调用、完整结果缓存、前缀缓存、共享随机源、样本来源及聚合权重。不同请求 ID 不证明独立，相同文本不证明复制。重放、确定性预处理缓存可以符合契约；需要新样本时将缓存结果当成多份独立证据才违反对应要求。

**验证**：用可记录样本身份的 stub 检查底层调用和来源。该测试验证机制，不证明真实模型独立性或投票准确率。采样键区分请求不能替代随机源检查。

## 观察还是干预

数据依赖图、时间顺序、统计相关和因果结构不能直接等同。列出局部违反、传播、恢复、最终要求各自证据。若目标是决定性原因，说明替换什么机制、固定什么环境、允许哪些后续调整以及如何判断成功。

**验证**：在隔离可重放环境修正候选步骤并运行后续流程，保留干预前后结果及副作用。随机环境需要重复和不确定性说明。成功修复说明这次干预有效，不自动证明该原因唯一、必要或最早；多故障系统可能需要联合修复。

没有可回放环境时给出区分假设的验证计划，候选保持 untested。错误被后续修复不证明没有历史影响；也不能把后面尚未执行的风险当成已观察到的最终失败。

依据：[Yin 与 Zhang，Markov categories, causal theories, and the do-calculus](https://arxiv.org/abs/2204.04821) 明确加入因果结构与干预语义。范畴化随机计算本身不能从不完整日志中识别根因。
