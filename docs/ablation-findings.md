# 四组消融后的迭代决定

本轮 96/96 次全部有效，没有工具调用或选择性重试。运行前冻结的方案、逐次结果和置信区间见 [报告](../evals/iterations/ablation-2026-09-29/REPORT.md)。本页是知道组别后的开发复盘，不是盲评；没有改动原始标签，也没有追加模型调用。

## 决定：不将 v2 候选升级为正式版本

| 条件 | 定位命中 | 定位准确率 | 输入 token 合计 |
| --- | ---: | ---: | ---: |
| A 无 Skill | 11/24 | 45.8% | 326,014 |
| B 旧版全包 | 11/24 | 45.8% | 480,904 |
| C 旧版正文 | 12/24 | 50.0% | 367,076 |

八个开发任务不足以确认泛化收益。所有预先声明的差值区间都包含 0；未作多重比较调整。v2 对无 Skill 少命中一次、对旧版正文少命中两次，没有支持它替换主 Skill 的证据。

旧版正文相对全包少用 23.7% 输入 token，但只多命中一次，来自 Algorithm-Generated:88 的一次成功。它可以支持继续研究按需加载的成本价值，不能证明准确率已提升。v2 虽比全包少用 27.3% 输入 token，也不能用省 token 掩盖其未达到预期的定位表现。

## 哪些假设得到支持，哪些需要撤回

**“旧版全包稳定降低定位准确率”没有在这次复测中复现。** A/B 在本次八任务上的逐任务平均定位得分完全相同。上一轮的下降仍是真实记录，但不能据此给某段指令下稳定有害的结论。尤其 #50，旧版全包从上一轮 0/3 变为本轮 2/3；两轮都只有三次重复，波动不能忽略。新旧两轮也不能合并后事后挑选一种更好看的统计口径。

**“增加来源追踪与恢复状态原则，就能修复归因”未获支持。** v2 在 #50 只命中 1/3，其余两次仍选择未执行的第 9 步；理由承认缺少执行结果，却仍偏向“最强的未恢复候选”。这说明写出证据原则并没有让最终选择稳定遵守它。#88 的 v2 三次都选择第 2 步，未解决最早引入者与后续重试者之间的归因问题。

这不证明某条新规则单独有害。本轮同时改变了正文长度、工作顺序和表述；各次生成也没有共享随机种子。可支持的判断仅为：这份候选整体未满足迭代预期。

**三个 Pro 开发案例四组都未命中位置。** 它们本来就是按难点选出的开发任务，不代表整个 Pro 数据集都为零。这里反复出现“日志中可见的错误”和“源标签选定的决定性/注入位置”之间的分歧：

- alfworld_alfagent_0288：四组均选择未拿枕头就使用灯的第 3 步；标签指向第 2 步的虚构记忆。回答认为虚构位置后来被实际观察确认，因此更像非决定性的早期错误。
- math_debate_0084：四组都能识别初始几何模型错误，标签却选第 1 轮的协调错误。恢复机会、错误传播与最终采纳必须分别表达，单个位置压缩了这些区别。
- dacode_smolagents_0096：轨迹第 2 步把布尔标记 count 当作重复数，但第 3 步正确执行去重，第 4 步写到错误的路径。标签选择第 2 步；上一轮和本轮的回答倾向实际产物交付问题。

这些分歧需要复核归因目标与环境中的反事实结果，不能靠修改标签给候选加分，也不能直接断言官方标签错误。所有成绩继续使用原始标签。

## 对范畴论框架的下一步调整

这次结果没有检验出范畴论理论本身的效果。它检验了向固定模型加入两份具体指令的行为。继续保留类型、组合与信息保持的框架，但下一步应让中间产物显式承载这些约束，而不只是增加提醒文字。

可实施的下一项假设是：**显式记录候选及其证据状态，能否降低最终归因时的目标漂移？** 拟检查的接口如下，尚未实现或评测，不作为本轮成果：

```text
TraceEvent = 事件 ID、动作主体、动作/观察、来源
Candidate = 原始事件引用、违反的要求、已观察/推断/待验证、恢复证据
Diagnosis<Target> = 明确目标、被选候选、支持与反证、未确定部分
```

每个交接保留原事件引用，不允许把“未执行风险”静默变成“已确认失败”；字段一致性可由程序检查，事实是否成立仍需轨迹或环境验证。增加结构不必增加多个 Agent 调用；先在一个上下文中检验这种记录是否改变行为。

针对 #50 一类情形，输出应能同时保留“第 3 步发生并恢复的局部错误”和“第 9 步尚未验证的风险”，而不迫使它们共用一个无区别的 failure 类型。对于只允许一个答案的外部基准，最后再按已声明目标投影为位置，继续严格计分。需要同时检验：这种额外表示是否真的减少错误，还是只增加 token。

## 后续范围

1. 主 Skill 和当前安装保持不变，v2 留作失败候选的可复核记录。旧版原有的按需阅读原则继续有效，但本轮正文消融不是原生按需读取的完整验证。
2. 暂不启动原计划中“候选值得保留后”的更大保留集运行。当前没有通过这一开发阶段的准确率依据，直接扩大同一候选只会增加成本。
3. 下一轮先设计可执行的证据状态验收和最小正常反例，并与同等工具条件下的无 Skill 对照。单独报告标签匹配、事实依据、恢复判断和修复验收；不混成一个主观总分。
4. 凡使用新中间表示或改变共同提示词，都需新建协议，并重新运行对应基线。不能将新成绩接在旧曲线上宣称进步。

本轮得到的是一次可复核的候选淘汰和加载成本测量。它帮助收窄下一步实验，没有证明新版本更强。
