# 局部与整体

适用于多智能体拆分、共享实体和结果合并。分发前声明覆盖哪些要求、共同字段、版本/单位、资源、所有权及比较方法。合并前检查重叠与整体约束。

在层模型中，局部截面经限制映射在重叠区一致，且模型满足层公理时，才有相应的唯一胶合保证。[Stacks Project](https://stacks.math.columbia.edu/tag/006S) 任意 Agent 任务集合不自动形成层；普通汇总也不是胶合证明。

## 两种独立检查

1. **兼容**：从局部产物抽取共同含义，检查同一实体、时间、单位与版本是否一致。有转换时检查三方以上的路径是否给出相同结果。
2. **整体可行**：检查要求覆盖、总预算、共享锁、资源容量、重复交付与缺口。两两兼容不能替代这一检查。

**反例**：每项任务消耗 4，预算 10；任意两项可行，但三项合计超限。若预算改成 12 且没有其他约束，不能因分发了三个 Agent 就继续报超限。

**验证**：注入共享单位或版本冲突，确认不会被合并器静默接受；另检查一个全局约束。冲突按已有规则转换、裁决或返工，不默认增加人类审批。若全部检查通过，只陈述已检查范围，不编造额外冲突。
